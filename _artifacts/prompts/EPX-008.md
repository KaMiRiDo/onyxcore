[EPX-008] Master Prompt: Native Previews & Hardware Decoder Management

Context: We are re-implementing the native media_kit hover preview architecture. To solve the Linux EGL context crash and support multi-platform environments, we are introducing a user-configurable Hardware Decoder setting with a smart "Auto-Cache" mechanism.

Please implement the following architecture across the application:
1. Hardware Decoder State & Auto-Caching

    Settings Storage (Hive/SharedPreferences):

        Add a property selectedHwDec (String). Default: auto.

        Add a property cachedResolvedHwDec (String). Default: null.

    The "Auto-Cache" Logic:

        When initializing the main video player, if selectedHwDec == 'auto':

            If cachedResolvedHwDec is NOT null, inject the cached value directly: platform.setProperty('hwdec', cachedResolvedHwDec).

            If cachedResolvedHwDec IS null, use a safe fallback chain: platform.setProperty('hwdec', 'vaapi,nvdec,vdpau,auto-safe').

        Resolution Listener: Once the first video successfully starts playing, query the engine for the actual driver it settled on using player.platform?.getProperty('hwdec-current'). If it returns a valid string (e.g., vaapi or nvdec), save this string to cachedResolvedHwDec in local storage. Please log it for verification purpose.

        If the user explicitly selects a driver from settings, bypass the cache and inject their choice directly.

2. Settings UI Integration (Settings -> General)

    New Section: Add a "Performance" menu section under the General settings tab.

    Dropdown Menu: Add a "Hardware Decoder" Dropdown with the following options:

        Auto (Recommended)

        VA-API (AMD / Intel)

        NVDEC (NVIDIA)

        D3D11VA (Windows Native)

        Software (CPU Decoding - Fallback)

    Restart Dialog: If the user changes this setting and clicks 'Save', intercept the save action and display a mandatory AlertDialog stating: "Hardware configuration changed. The application must be restarted for these changes to take effect." Provide an "OK" button that saves the new setting and safely terminates the app (exit(0)) or directs them to restart manually.

    Cache Clearing: If the user manually changes the setting, ensure cachedResolvedHwDec is cleared (set to null) so it doesn't conflict with their new choice.

3. Native Hover Previews (The "Warm Player")

    Initialization: Inside hover_preview.dart, create a secondary Player instance (_thumbnailPlayer).

    Decoder Injection: Read the actively resolved hardware decoder from the global state/cache and inject it into the _thumbnailPlayer just like the main player.

        _thumbnailPlayer.setProperty('hwdec', resolvedDecoder);

        _thumbnailPlayer.setProperty('aid', 'no'); (Disable audio)

        _thumbnailPlayer.setProperty('vd-lavc-fast', 'yes');

        _thumbnailPlayer.setProperty('vf', 'scale=240:-1'); (Native downscaling)

    Offstage Texture: media_kit requires a rendering context for native screenshots. Bind a VideoController to _thumbnailPlayer and render its Video widget inside an Offstage or a 1x1 pixel SizedBox in the widget tree.

    Strict Debounce Extraction:

        Implement a 150ms Debounce Timer. Do not use queues or throttles.

        On mouse move, cancel the timer.

        On timer complete: await _thumbnailPlayer.seek(position); followed by await _thumbnailPlayer.screenshot();

    UI Rendering: Render the resulting Uint8List via Image.memory() in the popup. Do not clear the previous image while the next one is processing to prevent flickering.
