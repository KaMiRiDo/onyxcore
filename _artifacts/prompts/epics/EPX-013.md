# Feature Implementation: OnyxCore Media Downloader (Full Stack)

We are implementing a high-performance, full-stack media downloader for the OnyxCore Linux file manager. This feature combines a native binary backend (`yt-dlp`, `gallery-dl`, `aria2c`) with a glassmorphic frontend UI.

## 1. Backend Architecture & Binary Management
Relying on Linux system package managers will result in outdated binaries. The app must manage its own toolchain.
* **Update Service:** Create a `DownloaderUpdateService` that fetches the latest stable release binaries of `yt-dlp` and `gallery-dl` directly from their official GitHub APIs.
* **Storage & Execution:** Store and grant executable permissions (`chmod +x`) to these binaries in `~/.local/share/onyxcore/bin/`. All process wrappers must point to this local directory first.
* **The Accelerator (`aria2c`):** Configure `yt-dlp` to utilize `aria2c` as the underlying download engine for maximum bandwidth utilization by passing the `--external-downloader aria2c` flag.

## 2. Process Wrappers & Task Integration
* **Command Execution:** Use `Process.start()` to execute the binaries. 
* **JSON Isolate Offloading:** When querying available formats (`yt-dlp -j <URL>`), the binaries return massive JSON dictionaries. Decoding and parsing this JSON payload into internal Dart data models MUST be offloaded to a background isolate using `compute` to prevent main-thread UI starvation.
* **Background Tasking:** Add a new download button in the top panel in between the settings and the background taskk button. ## 3. Frontend UI & Interactions
* **Keyboard Shortcut:** Implement a global listener for `Ctrl + Alt + D` to instantly open the Media Downloader dialog.
* **The Input State:** A glassmorphic dialog matching the OnyxCore theme opens with a URL text input field and a "Fetch/Analyze" button.
* **The Metadata State:** Once the background isolate parses the URL, the dialog dynamically expands to show:
  * **Visual Preview:** Media Thumbnail, Title, and Duration.
  * **Format Selection:** A dropdown populated with the available resolutions/formats from the JSON payload.
  * **Conditional Audio Toggle:** An "Audio Only" extraction checkbox. *Crucial:* Only render this toggle if the parsed metadata confirms the media is a video (hide it for image gallery links).
* **Location Selection:** A radio group to set the download destination:
  1. "System Downloads" (Default OS XDG Downloads folder).
  2. "Current Folder" (The directory currently active in the file manager view).
* **Action:** A "Download" button that pushes the task to the downloads section.
