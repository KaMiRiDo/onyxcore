# Feature Implementation: OnyxCore Archive Manager (Native 7z Wrapper)

We are implementing a streamlined, native-performance Archive Management feature for the OnyxCore Linux file manager. This module must handle extracting and compressing archives (ZIP, RAR, TAR, GZ, 7Z) with full password protection support.

To guarantee high performance and avoid Out-Of-Memory (OOM) crashes on large files, **do not use pure Dart archive packages**. You must build a wrapper around the system's `7z` / `p7zip` binary using Dart's `Process.start()`.

## 1. Core Feature Requirements

* **Context Menu & Interactions:** * Right-clicking standard files/folders should show a "Compress" option. 
  * Right-clicking an archive should show an "Extract" option.
  * **Double-Click Action:** Double-clicking an archive should immediately trigger the extract operation. It should automatically extract the contents into a new folder named after the archive within the current directory.
* **Password Support:** Both extraction and compression must handle password prompts from `7z`. If an archive is encrypted or the user requests encryption during compression, present a glassmorphic password dialog matching the OnyxCore UI before proceeding.
* **Background Tasks & History:** Compress and Extract operations must be dispatched to the existing `TaskProvider` (Background Task Manager). 
  * Stream the progress stdout from `7z` to update the task's progress bar.
  * Ensure the task history UI is elegantly designed, matching our matte/glassmorphic theme, showing success/failure states, file sizes, and completion times.

## 2. Performance & Security Safeguards (CRITICAL)

You must implement the following safeguards to prevent system instability:

* **Command Injection Prevention:** Never concatenate file paths into a raw shell string. You MUST pass arguments strictly as a `List<String>` to the `executable` parameter in `Process.start('7z', ['x', archivePath, '-o' + outputDir, ...])`.
* **Zombie Child Processes:** Store the `PID` of active `7z` compress/extract processes. Hook into the application's window close event to explicitly terminate these specific child processes so they do not continue running in the background if the user exits OnyxCore during a heavy extraction.
