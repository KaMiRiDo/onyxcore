# [EPX-009] Master Prompt: NLE Timecode Marker System (Sidecar Architecture)

**Context:** We are implementing a professional NLE (Non-Linear Editing) Timecode Marker System. Users can tag specific timestamps with text and emojis. To guarantee zero file corruption and instant I/O performance, this system will use a "Sidecar" architecture, storing metadata in a local `.json` file alongside the original video. keep the file in a separet hidden folder only.

Please implement this feature with the following architectural and UI requirements:

## 1. Data Architecture (The Sidecar Pattern)
- **Storage Strategy:** When a marker is created for a video (e.g., `/movies/trip.mp4`), immediately save it to a sidecar JSON file in the same directory (e.g., `/movies/.onyxcore/.trip.mp4.markers.json`).
- **Data Model:** Create a `VideoMarker` class containing: `id`, `timestamp` (Duration), and `content` (String).
- **Lifecycle:** - On video load: Check if the `.markers.json` file exists. If so, parse it into an in-memory list.
  - On marker save/edit/delete: Update the in-memory list and asynchronously overwrite the `.markers.json` file.

## 2. Settings & Visibility State
- **Settings Toggle:** Add a toggle in the Video Settings menu: "Show Markers on Timeline". 
- **Enforcement:** The 'T' shortcut to create a marker must ALWAYS work, regardless of this setting. However, if the setting is disabled, the markers should not be rendered on the progress bar.

## 3. Creation & Edit UI (The Frosted Editor)
- **Shortcut Hook:** Listen for the 'T' keyboard shortcut. When pressed:
  1. Pause the video playback (if playing).
  2. Display the Marker Editor UI anchored to the current timestamp on the progress bar.
- **Editor UI Constraints:**
  - **Style:** A frosted-glass (`BackdropFilter` with blur) popup container with a downward-pointing notch indicating the exact timestamp.
  - **Input:** A `TextField` limited to exactly **20 characters**, with a "Save" button.
  - **Emoji Picker:** Embedded above the text input inside the same frosted container. It must include:
    - A small search bar at the top to filter emojis.
    - A "Recently Used" section at the top of the emoji grid.
    - Tapping an emoji appends it to the text input.
- **Interaction:** Pressing 'Enter' or clicking 'Save' writes the marker to the sidecar file, closes the editor, and **automatically resumes video playback**. I need the tag to be immediately appeared once saved , if the settings is enabled to show.

## 4. Timeline Display UI (The Markers)
- **Rendering:** Render markers as `Positioned` widgets placed **above** the slider track. Each marker must have a downward-pointing notch that aligns precisely with its exact timestamp position on the progress bar.
- **Icon Logic:**
  - Default: A small red pin emoji (📍) inside the marker container.
  - Smart Emoji Detection: If the `content` string contains *only* a single emoji (no other text), display that specific emoji as the marker icon instead of the red pin.
- **Hover Tooltip:**
  - On hover, display a small frosted-glass tooltip above the marker showing the `content` text.
  - **Exception:** Do NOT show the tooltip if the `content` is empty OR if the content is only a single emoji (since the emoji is already visible as the icon).

## 5. Interaction Model
- **Single Click:** Instantly `seek` the video to the marker's timestamp and ensure playback is playing.
- **Double Click:** Pause the video and open the exact same "Frosted Editor" UI used for creation, pre-filled with the marker's existing content for editing.

## 6. Z-Index Stacking & Compatibility (Crucial)
- This feature must not conflict with the native hover preview implemented in `EPX-008`.
- Ensure the `Stack` ordering is strictly managed:
  1. Bottom: Progress Bar Slider.
  2. Layer 2: Timeline Markers.
  3. Layer 3: Marker Hover Tooltips.
  4. Layer 4: Marker Editor UI (when active).
  5. Top: Video Hover Preview Box (from EPX-008). 
- If a user hovers over the progress bar exactly where a marker is located, the EPX-008 preview box must render *above* the marker UI without interference.
